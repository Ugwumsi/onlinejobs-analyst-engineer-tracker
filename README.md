# OnlineJobs.ph Analyst/Engineer Tracker

Automated twice-daily digest of Data Analyst and Data Engineer postings from OnlineJobs.ph, filtered by job description (not just title) to exclude admin/VA/data-entry/lead-gen/mismatched-title listings.

- `report.html` — latest digest (served via GitHub Pages once enabled)
- `seen.json` — job IDs already reported, used for dedup across runs
